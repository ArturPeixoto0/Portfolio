# Portfólio Pessoal

Página web estática desenvolvida individualmente como parte de um desafio do processo trainee da iJunior.

O projeto teve como objetivo desenvolver uma página de perfil/portfólio utilizando HTML e CSS, além de aplicar, em um cenário individual, o fluxo de desenvolvimento **GitFlow** utilizado pela iJunior.

## 🎯 Objetivo

Criar uma página de portfólio pessoal simples, apresentando informações sobre o desenvolvedor, seus projetos e formas de contato, enquanto são aplicadas boas práticas de desenvolvimento e versionamento.

## ✨ Funcionalidades

- Seção "Sobre Mim";
- Apresentação de projetos;
- Seção de contato;
- Layout responsivo;
- Estruturação semântica da página;
- Organização visual utilizando CSS.

## 🛠️ Tecnologias

- **HTML5** — estruturação semântica da página;
- **CSS3** — estilização e construção do layout;
- **Flexbox/Grid** — organização dos elementos da interface;
- **Git** — versionamento do projeto;
- **GitHub** — hospedagem do código e gerenciamento dos branches e Pull Requests.

## 🌿 Fluxo de desenvolvimento

Como parte do desafio, o projeto foi desenvolvido simulando um ambiente profissional utilizando o fluxo GitFlow.

Foram utilizadas as seguintes branches principais:

- `main` — versão principal e estável do projeto;
- `homologacao` — ambiente destinado à validação;
- `desenvolvimento` — branch principal de desenvolvimento.

As funcionalidades foram desenvolvidas em branches `feature`, criadas a partir de `desenvolvimento`, e posteriormente integradas por meio de Pull Requests.

Os commits seguiram o padrão **Conventional Commits**.

### Fluxo utilizado

`feature` → `desenvolvimento` → `homologacao` → `main`

## 📁 Estrutura do projeto

- `index.html` — estrutura da página;
- `style.css` — estilos e layout;
- `images/` — imagens utilizadas na página, quando aplicável.

## 🚀 Como executar

Por se tratar de uma página web estática, não é necessário instalar dependências ou configurar um servidor.

Basta clonar o repositório e abrir o arquivo `index.html` em um navegador.

Este projeto foi desenvolvido individualmente como parte de um desafio do processo trainee da **iJunior**, com foco na aplicação prática de:
